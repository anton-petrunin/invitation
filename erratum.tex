\section*{Corrections to\\
An invitation to Alexandrov geometry:\\ CAT(0) spaces\\
{\normalsize  SpringerBriefs in Mathematics, 2019}
}

\today

\bigskip

\paragraph{page 14, line $\bm{(-16)}$:} Change ``Assume that $\spc{X}_n$ is...'' to ``Assume that $(\bm{X},\rho)$ is proper, $\spc{X}_n$ is...''

\paragraph{page 34--35:} the patchwork along a curve (3.2.2) has to be formulated for local geodesics only; minor changes in the proof are required.

\paragraph{page 44, line $\bm{(-4)}$.} The following\\
``By the globalization theorem (3.3.1), any proper length CAT(0) space is contractible. Therefore all proper...''\\
has to be changed to\\
``By 2.2.6, any proper length CAT(0) space is contractible. Therefore, by the globalization theorem (3.3.1), all proper...''

\paragraph{page 53, line 15:} Change ``\(\hat{\varphi^{-1}}(W)\)'' to ``\(\hat\varphi^{-1}(W)\)''.

\paragraph{page 63, lines 8--9 (Exercise 4.8.1):}  Change ``closed set bounded by a Lipschitz hypersurface'' to ``closed subgraph of a Lipschitz function \(f\colon \mathbb{R}^{m-1}\to\mathbb{R}\)''.

\paragraph{Bibliography:}
The numbers in some citations are shifted by 1; at least one citation is missing.
